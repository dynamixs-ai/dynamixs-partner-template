# Dynamixs.AI – BPMN Model Library

Here you can find BPMN tempmaltes and examples to get started. A BPMN file contains a complet process description and can be deployed into a running instance of Dynamixs.AI. The Model defines workflows that a user, service or AI-Agent can start. 

BPMN Model can be edited with the BPMN Tool [Open-BPMN](https://www.open-bpmn.org/). Folow the [Install Guide here](https://www.open-bpmn.org/install.html)
